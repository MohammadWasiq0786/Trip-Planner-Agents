# Trip Planner Agents


# Create Conda  env

```bash
conda create -p myenv python=3.10 -y
```

## Activate Conda env

```bash
conda activate myenv
```

## Conda env deactivate

```bash
conda deactivate
```

## Conda List

```bash
conda env list
```

## Remove Conda env

```bash
conda env remove -p myenv -y
```
